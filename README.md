# kroak ▆▆O▆O▆▂

A co-toad that will not take away your learning opportunity.

*Works on top of codex cli with hardcoded models - which is terrible design, but does it for me, personally.*

## Install


```sh
curl -fsSL https://raw.githubusercontent.com/fajtaiandris/kroak/main/install.sh | sh
```

Or build locally with `cargo install --path .`.

## Use

1. run `kroak` to start kroaking
2. each take is ephemeral and without context
3. toggle `don't look` to make kroak have context of your folder
4. start with `/but` to make kroak have context of the previous take
5. toggle `duh` to make kroak kroak a bit harder
